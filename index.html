TL;DR  ·  The story so far
Thirteen weeks of tracking and the storyline keeps escalating: from "is the code any good?" through "is the agent safe?" and "who pays the review cost?" to this week's blunt question — is the infrastructure load-bearing? A vendor outage, a budget cap, and a broken backup tool delivered the answer in a single week. The pattern holding the arc together: each new layer of AI dependence has surfaced a new failure mode no one priced in.
This week’s big story
Claude crashed, Uber tapped out, and rsync got the receipts
The AI coding tools the industry leans on hit a wall this week. On June 5, Anthropic's Claude and Claude Code went down hard — a bug let helper AIs make copies of themselves in a loop, draining users' weekly tokens in minutes. It's the first time the company's own agent runtime — not a customer's — broke that way.
Two days earlier, Uber told employees they get $1,500 per month, per tool for AI coding — after the company burned through its whole year's AI budget in four months. The same Monday, GitHub Copilot switched everyone to pay-as-you-go billing (1 credit = 1 cent). Then on June 4, The Register reported the backup tool rsync shipped broken software in version 3.4.3 — dozens of recent commits were written with Claude. A GitHub thread titled "Please Do Not Vibe Fuck Up This Software" said the quiet part loud.
When the tools that write our code go down or get expensive overnight, the bill comes due across the whole industry — not just for the people who chose to use them. Watch for: an Anthropic public post-mortem next week, and whether a second big company adopts Uber's monthly spending cap.
