## Headline
AI coding tools are the new attack surface — and the attackers are AI too

## Body
This week the security story around AI coding tools went from "there might be a problem" to "this is a distinct enterprise threat class." Security researchers documented [**agentjacking**](https://venturebeat.com/security/the-attack-that-hijacked-claude-code-came-through-sentry-datadog-pagerduty-and-jira-have-the-same-exposure) — a way to hijack Claude Code, Cursor, and Codex with a **single fake error message** slipped into a public Sentry feed. Datadog, PagerDuty, and Jira share the exact same weakness. In parallel, [**Wiz Research disclosed a flaw in Amazon Q**](https://www.wiz.io/blog/amazon-q-vulnerability) — CVE-2026-12957/58 — that lets any repository quietly steal a developer's AWS credentials just by opening it. Similar bugs exist in Claude Code and Windsurf. Amazon shipped a fix; the NSA published [**MCP security guidance**](https://www.nsa.gov/Press-Room/Press-Releases-Statements/Press-Release-View/Article/4496698/nsa-releases-security-design-considerations-for-ai-driven-automation-leveraging/); Adversa counts **30+ new MCP-related CVEs** since Q2.

The other half of the story is scarier: **AI agents are now the attackers, not just the target.** Sysdig documented [**JADEPUFFER**](https://www.sysdig.com/blog/jadepuffer-agentic-ransomware-for-automated-database-extortion) — the first end-to-end AI-driven ransomware, which encrypted **1,342 database configs** with an unrecoverable key. And [**Hugging Face — the world's largest AI model repository — was itself breached by an autonomous AI agent**](https://thehackernews.com/2026/07/worlds-largest-ai-model-repository.html) that harvested credentials and moved laterally through their systems, logging **17,000+ recorded attacker actions** before triage. Same week, xAI's Grok Build CLI was caught uploading entire code repositories, unredacted secrets and all.

## Why this matters
The tools developers were told to trust — Claude Code, Amazon Q, Grok Build — are being caught doing things nobody signed off on, and the attackers now run their own agents at scale. If you're a CTO, you need workspace-boundary audits and credential rotation this week, not this quarter. **Watch for:** whether a fourth production intrusion by an autonomous agent lands in the next two weeks — that would confirm this is a durable threat class, not a burst.
